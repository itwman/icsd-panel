# نسخهٔ ۱ (بایگانی)

کد نسخهٔ ۱ پنل فقط برای مرجع این‌جا مانده است و **نگه‌داری نمی‌شود؛ آن را نصب نکنید.**

ایرادهای امنیتی‌اش در [docs/ARCHITECTURE.md](../docs/ARCHITECTURE.md#چرا-بازنویسی) آمده‌اند.

بخش‌های مفیدش در فازهای بعدیِ نسخهٔ ۲ بازنویسی می‌شوند:

- TOTP (پیش از این منتقل شده)
- بک‌آپ SFTP
- قالب‌های Nginx
- DNS
